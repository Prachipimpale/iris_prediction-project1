# iris_prediction-project1
Iris Flower Classification 🌸

This project is a basic Machine Learning Classification project that predicts the species of an Iris flower using its physical measurements.

The project uses the Iris dataset available through Scikit-learn. The dataset contains measurements such as sepal length, sepal width, petal length, and petal width for three Iris species:

- Iris Setosa
- Iris Versicolor
- Iris Virginica

A machine learning classification model is trained using the flower measurements and tested on unseen data. The model's accuracy and performance are evaluated using appropriate evaluation metrics.

Objectives

- Understand the basics of machine learning classification.
- Load and explore the Iris dataset.
- Preprocess the dataset for model training.
- Train a classification model using Scikit-learn.
- Predict Iris flower species.
- Evaluate model accuracy and performance.
- Understand the difference between training and testing data.

Technologies Used

- Python
- Scikit-learn
- Pandas
- NumPy
- Matplotlib
- Google Colab / VS Code
- Jupyter Notebook

Dataset Features

The model uses four input features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

Target Classes

- Setosa
- Versicolor
- Virginica

Project Workflow

1. Download/load the Iris dataset.
2. Explore the dataset.
3. Separate input features and target labels.
4. Split the data into training and testing sets.
5. Train the machine learning classification model.
6. Make predictions on the test data.
7. Calculate model accuracy.
8. Evaluate the model performance.
9. Visualize the results where required.

Result

The trained machine learning model successfully classifies Iris flowers into their respective species based on their measurements. This project demonstrates the basic workflow of a supervised machine learning classification problem.

Conclusion

The Iris Flower Classification project provides a simple practical introduction to Machine Learning, Classification, Dataset Handling, Model Training, Prediction, and Performance Evaluation using Python and Scikit-learn.
